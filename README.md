# ankurjha-portfolio-

Personal portfolio website of **Ankur Jha** — Frontend Engineer specializing in luxury digital experiences, real-estate technology, 3D interactive visualizations, and high-performance web applications.

## 🚀 Built With
- **React 18** + **Vite**
- **Tailwind CSS** + Custom Vanilla CSS Design System
- **Lucide Icons**
- **Lenis Smooth Scroll**

## 🛠️ Getting Started Locally

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
